# Visual Bible — Version 1 (freeze before coding)

## Identity
World: cozy magical nursery crossed with 2001–2004 computer desktop. Pip is cute, soft, rounded, friendly, never spooky or gory. Existing official Pip asset pack is the visual character reference, not an invitation to redesign Pip.

## Locked initial palette
Cream #FFF4E7; Blush #F5C9DC; Lavender #C9B6E7; Starlight #FFE5A0; Plum #81638E; Midnight #25233F. Other colors only as tonal derivatives approved by the art operator. Dark mood uses Midnight backgrounds with subtle starlight accents, not a second unrelated style.

## Visual grammar
- Rounded windows, thin plum borders, subtle bevel/highlights, small retro UI labels, tasteful nostalgia.
- Hero Pip render is the primary focal point, with whitespace around silhouette; text always subordinate to the character.
- A single typography scale and window chrome system across all projects. Designer picks and records approved font(s) and licensing here.
- One clear visual spotlight per scene; avoid clutter. Motion directs attention along the intended reading path.
- Desktop shell, character, story, and project scenes must look like one world, not three separate mini-sites.
- No image-generated words or controls embedded in backgrounds. Render all interface text as HTML.

## Consistency checks
Pip's face, cap and proportions stay consistent from scene to scene. Lighting comes from a warm star/lantern; shadow/edge treatment stays consistent. Each scene transitions using shared motifs (moon, stars, glow). Repeat 4–6 visual motifs rather than inventing new ornaments everywhere.

## Mobile visual behaviour
Desktop look becomes compact panels and a bottom launcher, NOT a tiny squashed desktop. Use consistent type sizes, generous touch targets, no hover requirements. Stage the character prominently; keep decorative particles sparse on small screens.

## Fixed review screenshots
Request screenshots of 1440x900 desktop and 390x844 mobile for: Welcome, Origin midpoint, Nightlight open, Dream Delivery, Goodnight. Every visual PR is checked against both widths.
